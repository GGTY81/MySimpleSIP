# MySimpleSIP

Port para Linux (Ubuntu 26.04) do softphone MicroSIP 3.22.16 (Windows/MFC), em C++20 + Qt 6 Widgets + pjproject.

- Antes de qualquer trabalho, leia `docs/DIARIO_DO_PROJETO.md` (estado atual e próxima etapa) e, se necessário, `docs/ANALISE_E_PLANO.md` (análise e arquitetura).
- `reference/MicroSIP-3.22.16/` é o código original: somente leitura, nunca editar; arquivos com CRLF (use `tr -d '\r'` ao inspecionar). **Não é versionado** (`.gitignore`): contém `lib/Markup.*` e `atlrx.h`, que não podem ser redistribuídos — nunca copiar esses dois para `src/` (ver `docs/DESENVOLVIMENTO.md`).
- `reference/MicroSIP-3.22.12-assets/`: sons WAV e langpacks copiados do MicroSIP instalado no Bottles (`~/.var/app/com.usebottles.bottles/data/bottles/bottles/MicroSIP/drive_c/users/<usuário>/AppData/Local/MicroSIP/`). Essa instalação contém dados pessoais do usuário (contas, token do diretório): nunca copiar esses valores para o projeto.
- Repositório público: https://github.com/GGTY81/MySimpleSIP (branch `main`). O token de envio fica em `.credentials` (ignorado pelo git): nunca exibir, copiar para arquivos versionados nem gravar em `.git/config`; use-o só via `GIT_ASKPASS` temporário. Antes de cada envio, varrer o que vai para o repositório em busca de dados pessoais (contas, senhas, tokens, nome de usuário em caminhos).
- Documentação pública: `README.md`, `docs/INSTALACAO.md` (usuário, Ubuntu 26.04), `docs/DESENVOLVIMENTO.md` (desenvolvedor). Mantê-los atualizados ao mudar recursos ou o processo de compilação.
- Compilar: `./build.sh` (pjproject via `scripts/build-pjproject.sh`; dependências via `sudo ./scripts/install-deps.sh`). Executável: `build/src/mysimplesip`. Testar sem abrir janela: `QT_QPA_PLATFORM=offscreen ./build/src/mysimplesip --quit-after 1500`.
- Testes: `ctest --test-dir build` (GoogleTest em `tests/`). A camada `src/compat/` (`#include "afx.h"`) imita o MFC: ao portar código do MicroSIP, use-a em vez de reescrever com Qt/STL; se faltar algum método, implemente-o lá com a semântica do MFC e um teste.
- `tests/data/microsip_win.ini` é uma cópia ANONIMIZADA; qualquer novo dado de teste derivado da instalação do usuário deve ser anonimizado do mesmo jeito.
- Recursos gerados por script (não editar à mão): `resources/icons`, `resources/bitmaps`, `resources/resources.qrc`, `resources/RESOURCES.md` (`scripts/convert-resources.py`) e `docs/layout/dialogs.json`/`DIALOGOS.md` (`scripts/extract-dialogs.py`). Use `DIALOGOS.md` como referência de posições ao criar as telas Qt.
- Versionamento X.Y.Z (arquivo `VERSION`); ao concluir etapas, atualize o diário e, quando mudar a versão, o histórico de versões.
- Como portar um arquivo do MicroSIP: copiar o original (sem CR) para `src/...`, trocar só o que depende do Windows e marcar cada troca com `// MySimpleSIP:` (exemplo: `src/settings/settings.cpp`). Constantes em `src/common/define.h`/`const.h`.
- Núcleo ↔ UI: o código portado usa `PostMessage/SetTimer/AfxGetApp()->m_pMainWnd` (emulados em `compat/Win32Window.h`, a UI instala um `IMessageBackend`) e ganchos em `core/CoreHost.h` para chamadas diretas à interface. Testes com sanitizadores: `cmake -S . -B build-asan -DCMAKE_CXX_FLAGS="-fsanitize=address,undefined" ...` e `ctest --test-dir build-asan`.
- Teste do núcleo sem interface: `build/src/cli/msip-cli` (ver comentário no topo de `src/cli/msip_cli.cpp`) e `tests/sip-lab/loopback.sh` (precisa da porta UDP 5060 livre). Chamadas, presença e transferência reais pela janela: `MSIP_TEST_SIP=1 QT_QPA_PLATFORM=offscreen ./build/tests/test_ui` (portas UDP 5060/5070/5080 livres; com `sourcePort` ≠ 5060 o app também tenta a 5060, então suba primeiro a CLI da 5060). Nos testes, reinicie o `accountSettings` com `ResetAccountSettings()` (`tests/TestSettings.h`).
- Interface: `src/ui/` (`CmainDlg` deriva de `CmainDlgCore`); ícones por ID com `LoadImageIcon(IDI_...)`; posições com `DluX/DluY` a partir de `docs/layout/DIALOGOS.md`. Para ver a janela sem abrir na tela: `QT_QPA_PLATFORM=offscreen ./build/src/mysimplesip --screenshot /caminho/arquivo.png` (use `XDG_CONFIG_HOME/XDG_DATA_HOME/XDG_STATE_HOME` temporários para não tocar no perfil do usuário).
- Diálogos: monte com `CDialogLayout::Build(this, "IDD_...")` e acesse os controles pelo ID do `.rc` (`m_layout.Edit("IDC_...")`), como em `src/ui/AccountDlg.cpp`. Testes de interface em `tests/ui/` (offscreen). Na build ASan use `ASAN_OPTIONS=detect_leaks=0` (vazamentos herdados do original).
- O app é de instância única por arquivo INI (`QLocalServer` em `src/main.cpp`): para testar com o app do usuário aberto, use sempre `XDG_*` temporários (outro INI).
- Fidelidade ao original: manter nomes de funções, chaves INI e regras de decisão do MicroSIP na camada `src/core/`.
- Documentação e comunicação em português do Brasil.
